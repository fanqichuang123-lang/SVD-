SVD 灰度图像低秩近似实验网站

使用方法
1. 解压压缩包。
2. 双击打开 svd_image_lab.html。
3. 上传一张 PNG/JPG/WEBP/BMP 图片。
4. 网站会自动灰度化，并生成 k=10、20、50、100 的低秩近似图像。
5. 可分别下载四张重构图，也可下载实验指标 CSV。

功能
- 完全在浏览器本地运行，不上传图片。
- 固定 k=10、20、50、100。
- 输出相对 Frobenius 误差、MSE、数据比例、压缩倍数、能量保留率。
- 绘制奇异值衰减曲线。
- 为避免浏览器卡顿，大尺寸图片会自动缩放到适合计算的尺寸。

算法说明
网站使用随机化子空间方法求取主要奇异方向，再按照截断 SVD 的思想进行低秩重构。
当图片较小或最小边不足 100 像素时，k=100 会自动使用图片允许的最大有效秩，并在结果表中标注。

推荐浏览器
最新版 Chrome、Edge、Firefox 或 Safari。
